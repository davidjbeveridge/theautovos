# Auto Vos

Standalone copy of the approved Auto Vos static homepage. The site is at the repository root: `index.html`, `styles.css`, `app.js`, and `assets/`.

## Source

Copied from `davidjbeveridge/makelark-demos/auto-vos/` at commit `293b278b161223e853534c7d269a04875879b1ce`. All 15 website files are byte-for-byte unchanged, including the traced original logo, images, and desktop/mobile video. The existing demo remains in its original repository.

## Preview locally

Open `index.html`, or run `python3 -m http.server 8000` from this directory. No installation or build step is required.

## GitHub Pages

Use Settings > Pages > Deploy from a branch > `main` > `/ (root)`. Normal pushes then update the site; no custom deployment workflow is needed. `.nojekyll` is included. Copying the files does not itself activate Pages or change a custom domain.

Expected address after Pages activation: https://davidjbeveridge.github.io/theautovos/

This remains a preview: `noindex,nofollow` metadata and robots exclusion are retained. Quote/contact/service links still use the existing business website. No form backend or custom domain changes are included.
